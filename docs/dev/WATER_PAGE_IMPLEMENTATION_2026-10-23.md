# iOS 喝水页改版

按用户提供的饮水 App 参考和本轮选项答复实现：饮水为主，已有服用计划时显示一张服用卡。已修改本地源码，尚未进行 Xcode 编译或 iPhone 验收。

## 页面与交互

- 直接复用首页 `WaterBackground`，使用同一个 `wellness.waterFill`。实际累计量驱动水位；无目标时沿用明确标注的 2000 mL 满刻度，超目标显示真实数值而水位封顶。未增加动物轮廓或第二套水体。
- 顶部显示当日累计量、目标完成率和剩余量；未设置目标时提供设置入口。
- 中部显示距上次记录的时间、当日最近三条记录。点记录可修改饮品、容量、时间或删除；历史入口支持按日期查看、补记、删除，以及原有服用记录撤销。
- 常规字号下，快捷记录固定在底部系统 Tab 栏上方。横向选择水、茶、咖啡、牛奶、果汁、汽水、其他，再选 150/250/350/500 mL 或设置中的杯量，一键记录。自定义面板支持 1–5000 mL。成功保存才触发成功触感和可撤销反馈。
- 无障碍大字号时，快捷记录跟随整页滚动，避免固定底部面板占满屏幕；最近记录改为纵向列表。
- 服用卡只展示已设置时点的今日 B / D 计划，按时点排序；打开既有 `DoseSheet` 后逐次确认。无计划不占位，全部已记录时显示完成状态。不会因此开启系统通知或制造服用记录。
- 页面不可见或打开设置、历史、自定义、编辑、服用面板时暂停本页水体运动。继续沿用首页已有的前后台、减少动态、降低透明度和省电处理。

## 存档兼容

`WaterEntry` 增加 `drink` 字段，写入既有独立 `wellness-state.json`。旧记录缺失字段时读为水；未知类型读为其他并保留 ID、容量和日期。格式仍是可兼容的版本 1，未修改训练或体重存档。首页快捷入口默认记水，所有饮品的实际容量共同驱动首页和喝水页水位，不做补水系数换算。
